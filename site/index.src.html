{{en: How it works || fr: Comment ça marche}}

{{en: Three steps, two minutes. || fr: Trois étapes, deux minutes.}}

  1. 01

    {{en: Get Visual Enhancer || fr: Récupère Visual Enhancer}}

    {{en: The free engine by Merserk does the actual rendering. Download it from its releases and extract the ZIP. It is not bundled here on purpose: its license requires the author's written permission to redistribute it. || fr: Le moteur gratuit de Merserk fait le vrai rendu. Télécharge-le sur ses releases et extrais le ZIP. Il n'est pas embarqué ici volontairement : sa licence exige l'accord écrit de l'auteur pour le redistribuer.}}

  2. 02

    {{en: Install Valorant DLSS || fr: Installe Valorant DLSS}}

    {{en: Run the Setup from the latest release (per-user, no admin rights, FFmpeg included). The app finds Visual Enhancer by itself in Downloads, Desktop or Documents. || fr: Lance le Setup de la dernière release (par utilisateur, sans droits admin, FFmpeg inclus). L'app trouve Visual Enhancer toute seule dans Téléchargements, Bureau ou Documents.}}

  3. 03

    {{en: Drop, pick, run || fr: Dépose, choisis, lance}}

    {{en: Drop a clip, choose a style, press Run. Exports land in Videos\Valorant DLSS. || fr: Dépose un clip, choisis un style, appuie sur Lancer. Les exports arrivent dans Vidéos\Valorant DLSS.}}
