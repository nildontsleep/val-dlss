# The app says "Engine missing"

[Home](Home) · 🇬🇧 English · [🇫🇷 Français](#français)

## English

**Why.** The app drives [Visual Enhancer](https://github.com/Merserk/dlss5-visual-enhancer/releases) but does not contain it. It has to find the folder that holds `VE_CLI.exe`.

**Fix**
1. Download Visual Enhancer from its releases page and **extract the ZIP** (do not run it from inside the ZIP).
2. Open the app, click the ⓘ button → **Engine → Change**, and choose the folder that contains `VE_CLI.exe`.
3. The status in the top bar turns to "Engine ready".

The app looks by itself in Downloads, Desktop and Documents. If you extracted it elsewhere, pick it by hand once; the choice is remembered.

Still "Engine missing" although `VE_CLI.exe` is in the folder? [Open an issue](https://github.com/nildontsleep/val-dlss/issues/new/choose) with the folder path.

## Français

**L'app dit « Engine missing »**

**Pourquoi.** L'app pilote [Visual Enhancer](https://github.com/Merserk/dlss5-visual-enhancer/releases) mais ne le contient pas. Elle doit trouver le dossier qui contient `VE_CLI.exe`.

**Solution**
1. Télécharge Visual Enhancer depuis sa page de releases et **extrais le ZIP** (ne le lance pas depuis l'intérieur du ZIP).
2. Ouvre l'app, clique sur le bouton ⓘ → **Moteur → Changer**, et choisis le dossier qui contient `VE_CLI.exe`.
3. Le statut en haut passe à « Engine ready ».

L'app cherche toute seule dans Téléchargements, Bureau et Documents. Si tu l'as extrait ailleurs, indique-le à la main une fois ; le choix est mémorisé.

Toujours « Engine missing » alors que `VE_CLI.exe` est dans le dossier ? [Ouvre une issue](https://github.com/nildontsleep/val-dlss/issues/new/choose) avec le chemin du dossier.
