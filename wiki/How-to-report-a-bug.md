# How to report a bug so it gets fixed

[Home](Home) · 🇬🇧 English · [🇫🇷 Français](#français)

## English

First check the other pages of this FAQ and the [existing issues](https://github.com/nildontsleep/val-dlss/issues?q=is%3Aissue). Then [open a bug report](https://github.com/nildontsleep/val-dlss/issues/new/choose) with:

1. **App version** (it is in the file name: `Valorant-DLSS-Setup-x.y.z.exe`) and *installer or portable*.
2. **Windows version**, **GPU and NVIDIA driver version**.
3. **Visual Enhancer version** (and ffmpeg version if the preview, TikTok or Max size is involved).
4. The **exact text** of the error on the card (copy it, or a screenshot) and the **steps** to reproduce.
5. Does the same clip work in Visual Enhancer alone?

**No support in Discord DMs or servers, except for major bugs** (even then, please open an issue too): see the [Support policy](https://github.com/nildontsleep/val-dlss/blob/main/SUPPORT.md).

## Français

**Comment signaler un bug pour qu'il soit corrigé**

Regarde d'abord les autres pages de cette FAQ et les [issues existantes](https://github.com/nildontsleep/val-dlss/issues?q=is%3Aissue). Puis [ouvre un rapport de bug](https://github.com/nildontsleep/val-dlss/issues/new/choose) avec :

1. La **version de l'app** (elle est dans le nom du fichier : `Valorant-DLSS-Setup-x.y.z.exe`) et *installeur ou portable*.
2. La **version de Windows**, le **GPU et la version du pilote NVIDIA**.
3. La **version de Visual Enhancer** (et de ffmpeg si l'aperçu, TikTok ou Max size est concerné).
4. Le **texte exact** de l'erreur sur la carte (copie-le, ou une capture) et les **étapes** pour reproduire.
5. Est-ce que le même clip marche dans Visual Enhancer seul ?

**Pas de support en MP Discord ni sur un serveur, sauf pour les bugs majeurs** (même dans ce cas, ouvre aussi une issue) : voir la [politique de support](https://github.com/nildontsleep/val-dlss/blob/main/SUPPORT.md).
