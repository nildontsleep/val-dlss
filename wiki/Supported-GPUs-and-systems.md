# Which GPUs and systems are supported?

[Home](Home) · 🇬🇧 English · [🇫🇷 Français](#français)

## English

- **Windows 11, 64-bit** only. No macOS, no Linux.
- A **GeForce RTX** GPU supported by Visual Enhancer's Neural Rendering, with a current NVIDIA driver. The exact list is Visual Enhancer's, not ours: read its README. **GTX, AMD and Intel GPUs do not work** for Neural Rendering.
- **Max size** re-encoding also needs an NVIDIA GPU with NVENC.
- Phones, tablets and web browsers: no.

If it works in Visual Enhancer alone, it works here. If it does not, ask [its repository](https://github.com/Merserk/dlss5-visual-enhancer/issues) about GPU support.

## Français

**Quels GPU et systèmes sont gérés ?**

- **Windows 11, 64 bits** uniquement. Pas de macOS, pas de Linux.
- Une carte **GeForce RTX** gérée par le Neural Rendering de Visual Enhancer, avec un pilote NVIDIA récent. La liste exacte est celle de Visual Enhancer, pas la nôtre : lis son README. Les cartes **GTX, AMD et Intel ne marchent pas** pour le Neural Rendering.
- Le ré-encodage de **Max size** demande aussi une carte NVIDIA avec NVENC.
- Téléphones, tablettes et navigateurs : non.

Si ça marche dans Visual Enhancer seul, ça marche ici. Sinon, pose la question sur [son dépôt](https://github.com/Merserk/dlss5-visual-enhancer/issues) pour le support GPU.
