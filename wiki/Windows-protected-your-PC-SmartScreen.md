# Windows SmartScreen or my antivirus blocks the app

[Home](Home) · 🇬🇧 English · [🇫🇷 Français](#français)

## English

**Why.** The executables are **not code-signed** (a certificate costs money every year), so SmartScreen warns about any unknown unsigned app, and some antivirus tools are suspicious of unsigned Electron apps.

**Fix**
- SmartScreen: click **More info → Run anyway**.
- The code is public and the files are built by [GitHub Actions](https://github.com/nildontsleep/val-dlss/actions) from this repository. Download **only** from the [Releases](https://github.com/nildontsleep/val-dlss/releases) page of this repository.
- If you prefer, build it yourself: see *Development* in the README.

Anyone selling you this app, or hosting it elsewhere, is not the project: get it from Releases.

## Français

**Windows SmartScreen ou mon antivirus bloque l'app**

**Pourquoi.** Les exécutables ne sont **pas signés** (un certificat coûte de l'argent chaque année) : SmartScreen avertit pour toute app inconnue non signée, et certains antivirus se méfient des apps Electron non signées.

**Solution**
- SmartScreen : clique sur **Informations complémentaires → Exécuter quand même**.
- Le code est public et les fichiers sont construits par [GitHub Actions](https://github.com/nildontsleep/val-dlss/actions) à partir de ce dépôt. Télécharge **uniquement** depuis la page [Releases](https://github.com/nildontsleep/val-dlss/releases) de ce dépôt.
- Si tu préfères, compile-le toi-même : voir *Développement* dans le README.

Quiconque te vend cette app, ou l'héberge ailleurs, n'est pas le projet : prends-la sur Releases.
