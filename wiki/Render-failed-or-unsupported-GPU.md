# A render fails ("Failed")

[Home](Home) · 🇬🇧 English · [🇫🇷 Français](#français)

## English

The card shows the error text. What it usually means:

- **The text comes from Visual Enhancer** (GPU not supported, model unavailable, crash in its render): this is **not an app bug**. Check Visual Enhancer's README for its requirements (Windows 11, a GeForce RTX GPU supported by its Neural Rendering, a current NVIDIA driver) and report it in [its repository](https://github.com/Merserk/dlss5-visual-enhancer/issues).
- **It works in Visual Enhancer alone but not in the app**: that one is for us. [Open a bug report](https://github.com/nildontsleep/val-dlss/issues/new/choose) with the exact text of the card.
- **Every render fails although Visual Enhancer and FFmpeg work on their own**: that is a *major bug* (see the [Support policy](https://github.com/nildontsleep/val-dlss/blob/main/SUPPORT.md)).

AMD and Intel GPUs are not supported, nor GTX cards: see [Supported GPUs and systems](Supported-GPUs-and-systems).

## Français

**Un rendu échoue (« Failed »)**

La carte affiche le texte de l'erreur. Ce que ça veut dire en général :

- **Le texte vient de Visual Enhancer** (GPU non géré, modèle indisponible, plantage de son rendu) : ce n'est **pas un bug de l'app**. Vérifie les prérequis dans le README de Visual Enhancer (Windows 11, une carte GeForce RTX gérée par son Neural Rendering, un pilote NVIDIA récent) et signale-le dans [son dépôt](https://github.com/Merserk/dlss5-visual-enhancer/issues).
- **Ça marche dans Visual Enhancer seul mais pas dans l'app** : celui-là, c'est pour nous. [Ouvre un rapport de bug](https://github.com/nildontsleep/val-dlss/issues/new/choose) avec le texte exact de la carte.
- **Tous les rendus échouent alors que Visual Enhancer et FFmpeg marchent seuls** : c'est un *bug majeur* (voir la [politique de support](https://github.com/nildontsleep/val-dlss/blob/main/SUPPORT.md)).

Les cartes AMD, Intel et GTX ne sont pas gérées : voir [GPU et systèmes gérés](Supported-GPUs-and-systems).
