# Where are my exports?

[Home](Home) · 🇬🇧 English · [🇫🇷 Français](#français)

## English

By default in **`Videos\Valorant DLSS`**. The button showing a folder name at the bottom changes it. Each finished clip card has an **open folder** button.

- File names end with `_Neural_Rendering.mp4`, or `_tiktok.mp4` with the TikTok method.
- **Compare** puts each style in `<clip name>\style-0`, `style-1`, `style-2`.
- Rendering the same clip again never overwrites: the new file gets ` (2)`, ` (3)`…

Nothing is uploaded anywhere. Your original clips are never modified.

## Français

**Où sont mes exports ?**

Par défaut dans **`Vidéos\Valorant DLSS`**. Le bouton avec un nom de dossier, en bas, permet de le changer. Chaque carte de clip terminé a un bouton **ouvrir le dossier**.

- Les fichiers finissent par `_Neural_Rendering.mp4`, ou `_tiktok.mp4` avec la méthode TikTok.
- **Comparer** range chaque style dans `<nom du clip>\style-0`, `style-1`, `style-2`.
- Refaire le même clip n'écrase jamais rien : le nouveau fichier reçoit ` (2)`, ` (3)`…

Rien n'est envoyé nulle part. Tes clips d'origine ne sont jamais modifiés.
