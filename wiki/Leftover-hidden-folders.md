# A hidden ".vdlss-…" folder is left in my output folder

[Home](Home) · 🇬🇧 English · [🇫🇷 Français](#français)

## English

While a clip renders, the work happens in a **hidden folder named `.vdlss-<number>`** inside the output folder, and the result is moved out when it is done. The folder is deleted automatically when the render ends, fails or is cancelled.

If one is left (the app was killed, the PC crashed, a power cut), it is **safe to delete once the app is closed**. It may still contain a finished render: look inside before deleting if a clip seems missing.

## Français

**Un dossier caché « .vdlss-… » reste dans mon dossier de sortie**

Pendant le rendu d'un clip, le travail se fait dans un **dossier caché nommé `.vdlss-<nombre>`** à l'intérieur du dossier de sortie, et le résultat en est déplacé à la fin. Le dossier est supprimé automatiquement quand le rendu se termine, échoue ou est annulé.

S'il en reste un (app tuée, PC planté, coupure de courant), tu peux le **supprimer sans risque une fois l'app fermée**. Il peut encore contenir un rendu terminé : regarde dedans avant de supprimer si un clip te semble manquer.
