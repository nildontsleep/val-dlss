# "ffmpeg is required"

[Home](Home) · 🇬🇧 English · [🇫🇷 Français](#français)

## English

The preview, the TikTok method and Max size use **ffmpeg**.

- The **installer** (`Valorant-DLSS-Setup-x.y.z.exe`) **includes** it: nothing to do. If you still see this message, reinstall with the Setup.
- The **portable** version does not include it: download a Windows build of `ffmpeg.exe` from [ffmpeg.org](https://ffmpeg.org/download.html), then click **Choose ffmpeg.exe** in the message (or ⓘ → ffmpeg → Change). The app also finds it by itself if it sits in Visual Enhancer's folder or in your `PATH`.
- "This ffmpeg.exe does not start": choose another build.

Without ffmpeg you can still render with **TikTok** off and **Max size** empty.

## Français

**« ffmpeg est nécessaire »**

L'aperçu, la méthode TikTok et Max size utilisent **ffmpeg**.

- L'**installeur** (`Valorant-DLSS-Setup-x.y.z.exe`) l'**inclut** : rien à faire. Si tu vois quand même ce message, réinstalle avec le Setup.
- La version **portable** ne l'inclut pas : télécharge un `ffmpeg.exe` Windows sur [ffmpeg.org](https://ffmpeg.org/download.html), puis clique sur **Choisir ffmpeg.exe** dans le message (ou ⓘ → ffmpeg → Changer). L'app le trouve aussi toute seule s'il est dans le dossier de Visual Enhancer ou dans ton `PATH`.
- « Ce ffmpeg.exe ne démarre pas » : choisis une autre build.

Sans ffmpeg, tu peux quand même rendre avec **TikTok** désactivé et **Max size** vide.
